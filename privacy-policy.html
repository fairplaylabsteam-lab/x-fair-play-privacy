Privacy Policy

X Fair Play - Quick Follow Manager

Effective Date: August 16, 2026  |  Last Updated: August 16, 2026

🛡️ Commitment to User Privacy: We strictly respect your privacy. X Fair Play - Quick Follow Manager does NOT collect, store, transmit, share, or sell any personal data, account credentials, browsing history, or sensitive information to any external servers or third parties.

1. Introduction

This Privacy Policy explains how X Fair Play - Quick Follow Manager ("Extension", "we", "us", or "our") operates and handles user information when you install and use our Chrome browser extension.

Our core philosophy is 100% Client-Side Operation. All processing occurs locally on your own computer within your browser session.

2. Single Purpose Description

The sole purpose of the Extension is to provide a lightweight productivity management tool for users on X (formerly Twitter) to organize their following and follower lists directly in their browser. It automates user-directed actions such as Unfollowing non-mutual accounts, Following back verified accounts, Following all followers, and Unfollowing all following accounts.

3. Information Collection and Data Usage

  • No Personal Identifiable Information (PII) Collected: The extension does not collect usernames, passwords, authentication tokens, cookies, email addresses, IP addresses, or payment details.
  • No External Server Communication: The extension has no external backend servers or database tracking. All actions are executed via direct interaction between your browser and the active X (twitter.com / x.com) web pages you visit.
  • No Analytics or Third-Party Tracking: We do not employ Google Analytics, telemetry scripts, advertising trackers, or tracking pixels.
  • Local Storage Only: Any user configurations (such as custom whitelist handles, daily action limits, task delays, UI language preferences, and recent action logs) are stored strictly locally on your machine using Chrome's built-in chrome.storage.local API.

4. Permissions Used & Justifications

In accordance with Chrome Web Store Developer Policies, the Extension requests only the minimum required permissions necessary to execute its declared core functionality:

Permission Purpose & Justification
alarms Schedules background countdown timers (specifically the 40-minute rate-limit cooldown) via chrome.alarms. This ensures the timer keeps running accurately even when the popup or side panel is closed, waking up the background service worker to alert the user and safely resume tasks.
storage Saves user settings, whitelist lists, action delay preferences, language selection, and action logs locally on the user's device via chrome.storage.local.
sidePanel Enables the extension interface to be pinned alongside your X browsing tab via Chrome's native Side Panel feature.
notifications Sends native desktop notifications to inform the user when an action batch finishes or when a rate limit cooldown has elapsed.
tabs Detects if an appropriate X page (e.g. x.com/following) is already open and allows opening or navigating to the correct target page when the user initiates a task.
Host: https://x.com/*, https://twitter.com/* Restricts script execution strictly to official X/Twitter domains to interact with profile follow/unfollow lists. No other websites are accessed.

5. Remote Code Policy Compliance

In compliance with Chrome Manifest V3 regulations, X Fair Play - Quick Follow Manager does NOT load or execute any remote scripts, remote styles, eval, or external code. All application code is completely self-contained within the extension package installed from the Chrome Web Store.

6. Data Security and Third-Party Disclosure

  • We do NOT sell, trade, rent, or transfer any user data to third parties.
  • We do NOT use or transfer user data for purposes unrelated to the core functionality of the extension.
  • We do NOT use or transfer user data to determine creditworthiness or for lending purposes.

7. User Control & Data Deletion

You maintain full control over your data at all times:

  • You can clear all stored logs and settings at any time directly through the extension's Settings menu.
  • Uninstalling the Extension from Chrome immediately and permanently removes all locally stored extension data from your device.
